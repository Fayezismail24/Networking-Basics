All five ports are 10/100/1000 Gigabit Ethernet.

Port 1 (Internet / PoE in): * Internet: By default, this is your WAN port. This is where you plug the cable coming from your ISP modem.

PoE in: This port also supports Passive Power over Ethernet. You can power the entire router through this port using a PoE injector, meaning you wouldn't need to use the DC power jack.

Ports 2, 3, 4, & 5 (LAN):

These are your Local Area Network ports. You use these to connect your wired devices, like a PC, a Wi-Fi Access Point, or a network switch.

In the default configuration, these four ports act like a built-in switch.
