# MikroTik Overview

## Introduction to MikroTik

**MikroTik** is a Latvian company that produces network equipment and software solutions. The company's **RouterOS** is one of the most popular and powerful operating systems for routers, providing users with comprehensive networking features like routing, firewall, bandwidth management, and more.

MikroTik products are widely used in ISPs (Internet Service Providers), small businesses, and home networks due to their affordability and robust capabilities.

---

## What is RouterOS?

**RouterOS** is MikroTik’s proprietary operating system designed specifically for **networking devices**. It is installed on MikroTik’s hardware, such as **RouterBoards**, and can also run on **x86** hardware. RouterOS offers advanced network configuration tools, including support for:

- **Routing Protocols**: BGP, OSPF, RIP, and more.
- **Firewalling**: Stateful and stateless packet inspection, filtering.
- **NAT (Network Address Translation)**: Simple and complex routing solutions.
- **VLAN Support**: For efficient network management and segmentation.
- **VPN (Virtual Private Network)**: PPTP, L2TP, IPsec, OpenVPN, etc.
- **Quality of Service (QoS)**: Traffic shaping, bandwidth management, and prioritization.
- **Wireless Networking**: Including hotspot management, Wi-Fi bridge, etc.

RouterOS allows users to run their devices as full-fledged routers, access points, firewalls, VPN servers, or even **simple home gateways**.

---

## MikroTik Hardware

MikroTik produces a variety of **networking devices** like:

1. **RouterBoard**: These are specialized devices running RouterOS, including models like hAP (home access point), CCR (Cloud Core Router), and more.
2. **Cloud Core Routers (CCR)**: High-performance devices designed for larger networks or ISP-level deployments.
3. **RB (RouterBoard)**: Small, cost-effective devices aimed at SOHO (small office/home office) and SOHO ISPs.
4. **Wireless Systems**: Including **access points**, **repeaters**, and **CPE (Customer Premise Equipment)** devices.

These devices are compatible with **RouterOS** and come with different specifications (e.g., number of ports, CPU power, Wi-Fi capabilities).

---

## Features of MikroTik RouterOS

### 1. Routing

RouterOS supports various **routing protocols**, such as:

- **Static Routing**: Simple routes for straightforward network designs.
- **Dynamic Routing**: Support for **OSPF**, **RIP**, **BGP**, etc.
- **ECMP (Equal-Cost Multi-Path)**: Load balancing across multiple routes.
- **MPLS (Multiprotocol Label Switching)**: For efficient data forwarding in large networks.

### 2. Firewall

RouterOS has a powerful **firewall** that provides:

- **Packet Filtering**: Allow or block traffic based on various criteria (IP, ports, protocols).
- **NAT (Network Address Translation)**: Port forwarding, masquerading, and more.
- **Stateful Inspection**: Tracks the state of active connections for security.
- **Connection Tracking**: Provides enhanced control and security over connections.
  
### 3. VPN (Virtual Private Network)

RouterOS includes **multiple VPN solutions**:

- **PPTP**, **L2TP**, **IPsec** VPN support.
- **OpenVPN**: Secure remote access and site-to-site connections.
- **L2TP/IPsec**: Fast and secure communication.

### 4. QoS (Quality of Service)

RouterOS includes features for traffic management, including:

- **Bandwidth Limiting**: Set limits for specific IP addresses or subnets.
- **Queueing**: Advanced queuing for bandwidth shaping and prioritization.
- **Simple Queues and PCQ**: For easy management of internet connections and resources.

### 5. Wireless Features

RouterOS supports **wireless networking**, offering:

- **Wireless Access Points (APs)**: You can configure your device as an access point.
- **Wireless Bridges**: Connect two LANs through a wireless bridge.
- **Wi-Fi Security**: WPA, WPA2 encryption for secure wireless communications.
- **Hotspot System**: Create Wi-Fi hotspots with user authentication.

### 6. Hotspot Management

MikroTik's **Hotspot** feature allows you to set up a **public Wi-Fi system** with:

- Custom login pages.
- User authentication via a portal.
- Integration with billing systems.
  
### 7. User Management

- **Users & Groups**: Manage permissions for different users.
- **Radius Server**: For centralized authentication.

### 8. Monitoring and Reporting

RouterOS has several **monitoring tools**:

- **Traffic Stats**: See which services are using the most bandwidth.
- **System Logs**: Keep track of system events.
- **Graphs and Bandwidth Usage**: Visualize performance with built-in graphs.
  
### 9. Scripting and Automation

RouterOS supports a built-in scripting language for:

- Automation of network tasks (e.g., backups, reporting).
- Complex network operations, triggering based on events.

## Setting up MikroTik RouterOS

### Installation on Hardware (RouterBoard)

- RouterOS comes pre-installed on MikroTik hardware (RouterBoards).
- For **x86 hardware**, you need to install RouterOS manually using an image file.

### Basic Configuration

Here’s a high-level guide to setting up RouterOS:

1. **Access the Router**: Connect through Winbox (a GUI-based tool) or use the web interface.
2. **Set Up IP Addresses**: Configure IP addresses on interfaces (e.g., LAN, WAN).
3. **Configure Routing**: Define static or dynamic routes.
4. **Set Up Firewall**: Use firewall rules for security.
5. **Wireless Setup**: Set up wireless interfaces if using MikroTik wireless devices.
6. **Enable NAT**: Set up NAT to allow internet access for devices behind the router.
