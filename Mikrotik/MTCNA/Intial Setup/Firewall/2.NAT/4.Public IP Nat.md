## Source NAT (SRC-NAT) Implementation

Unlike Masquerade, which automatically uses the IP assigned to an interface, **SRC-NAT** is used when you have a specific, static public IP address that you want your internal devices to use when communicating with the internet.

### Network Scenario

In this lab, we are configuring a rule to ensure that all traffic originating from a specific internal host is translated to a designated public IP address before it leaves the network.

* **Internal Source IP**: `10.0.0.17`
* **Static Public IP**: `45.42.144.21`
