In a network environment, **Masquerade** is a specialized form of **Source NAT (SRC-NAT)** designed for situations where the router’s public IP address might change (dynamic IP), which is common with home or small business internet connections.

### 1. What is Masquerade?

When a device on your local network (like your laptop) wants to talk to a server on the internet (like Google), it uses a private IP address. Since private IPs cannot navigate the public internet, the router uses **Masquerade** to "hide" the private IP behind its own Public IP.

* **The Logic**: The router takes the packet, replaces the "Source IP" with its own WAN IP, and keeps track of this in a connection table.
* **The Result**: To the internet, all traffic from your house looks like it is coming from one single device—the router.

---

### 2. Why "Masquerade" instead of "Source NAT"?

In MikroTik and Linux, there are two ways to do this, but Masquerade is the most popular for SysAdmins:

| Feature | Action: `src-nat` | Action: `masquerade` |
| --- | --- | --- |
| **IP Type** | Use with **Static** Public IPs. | Use with **Dynamic** Public IPs (DHCP/PPPoE). |
| **Behavior** | You must manually specify the IP. | Automatically detects the IP on the interface. |
| **Connection** | Keeps connections alive if the link flaps. | Clears the connection table if the link drops. |

## 9. Source NAT: Masquerade

While **Destination NAT** is for traffic coming *in*, **Masquerade** is used for traffic going *out* to the internet.

### Configuration
* **Chain**: `srcnat`
* **Out. Interface**: `ether1-gateway` (Your WAN port)
* **Action**: `masquerade`

### How it Works
1. A client (192.168.0.21) sends a request to Google.com.
2. The router receives the packet and sees the **Out-Interface** is the internet.
3. The router performs **Masquerade**, changing the source address from `192.168.0.21` to the router's **Public IP**.
4. When Google replies, the router remembers the client and sends the data back to `192.168.0.21`.

> **SysAdmin Tip**: Always specify the `Out. Interface`. If you don't, the router might try to masquerade internal traffic (LAN to LAN), which can break local services like printers or file shares!
