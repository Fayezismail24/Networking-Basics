## Registration Table

The **Registration Table**  is the real-time monitoring hub for all active wireless links.

* **Live Monitoring**: It allows you to view all currently connected wireless interfaces.
* **Dual View**:
* If the router is an **AP**, it shows all connected clients.
* If the router is a **station**, it shows the specific Access Point it is currently connected to.


* **Key Data Points**: The table provides critical performance metrics including **Uptime**, **Signal Strength (Tx/Rx)**, and **Data Rates** (e.g., 48Mbps or 144.4Mbps).
