
## 📻 What is Radio Name in MikroTik Wireless?

**Radio Name** is a **text label** that identifies the wireless radio itself.

- It is **not** the SSID
- It is **not** the interface name
- It is used for **identification and monitoring**

---

## 🔍 Where is Radio Name Used?

- Appears in:
  - Registration Table
  - Snooper
  - Scan results
- Helps identify **which physical radio** is transmitting

Example:
- Device has 2 radios
- Both may use same SSID
- **Radio Name distinguishes them**

---

## ⚙️ Radio Name vs SSID

| Feature | Radio Name | SSID |
|-------|-----------|------|
| Visible to users | ❌ No | ✅ Yes |
| Visible to admins | ✅ Yes | ❌ No |
| Used for connection | ❌ No | ✅ Yes |
| Purpose | Identification | Network access |

---

## 🧠 MikroTik Exam Tip

If the question says:
> “Used to identify the wireless radio”

👉 Correct answer: **Radio Name**

---

## 🧪 Example

- SSID: Office-WiFi
- Radio Name: AP-5GHz-Rooftop

Clients connect to **SSID**,  
Admins troubleshoot using **Radio Name**.
