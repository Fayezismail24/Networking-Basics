### Wireless Chains and MIMO

* **802.11n** introduced **MIMO** (Multiple Input, Multiple Output), which allows a wireless device to send and receive data using **multiple antennas** at the same time.
* **SISO** (Single Input, Single Output) uses just **one antenna**, limiting speed to **72.2 Mbps** on **802.11n** devices.
* With **MIMO** (multiple antennas), the device can achieve much faster speeds by sending data over multiple paths, improving performance.

In simple terms, **MIMO** boosts your wireless speed by using more antennas to send and receive data at once.


* **More antennas allow for more data streams**, which increases the overall throughput and reliability of the wireless connection.
* In **MIMO systems**, each antenna can send or receive its own stream of data. So, with more antennas, **the data can be transmitted faster and more efficiently**.
* **Multiple antennas help improve signal quality** by utilizing **multiple paths** for data to travel, which also reduces interference and dead spots.

### Key Takeaways:

* **More antennas = better performance** (more data streams and faster speeds).
* However, the **router** and **client device** must both support the same number of antennas for maximum performance.
