| Color  | Meaning                              | Usage Level                         |
|--------|--------------------------------------|-------------------------------------|
| Green  | Normal: The user is well within limits. | 0% – 50% of Max Limit used          |
| Yellow | Warning: The user is consuming significant bandwidth. | 51% – 75% of Max Limit used |
| Red    | Critical / Throttled: The user reached the limit and is being throttled. | 76% – 100% of Max Limit used |
