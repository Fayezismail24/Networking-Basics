

# MikroTik RouterOS Update Channels

In the **MikroTik RouterOS** "Check For Updates" window, you can choose from the following update channels:

## 1. Upgrade
- **Purpose:** This channel is used for **upgrading** your RouterOS to the **latest stable version**. It includes stable and tested features that are safe for production environments.
- **Use Case:** Ideal for users who want to get the most recent stable version of RouterOS, which is recommended for most users.
- **Installation Action:** Clicking "Download & Install" will automatically download and install the latest stable release.

## 2. Long Term
- **Purpose:** The **Long-Term** (LTS) channel provides **long-term supported versions** of RouterOS. LTS versions are stable and maintained for extended periods (years) with critical bug fixes and security patches, but they do not receive the latest features as quickly as stable or testing versions.
- **Use Case:** Ideal for **enterprise networks** or users who need a stable, long-term supported version with minimal changes.
- **Installation Action:** Clicking "Download & Install" will install an LTS version, which is very stable but may lack the latest features.

## 3. Stable
- **Purpose:** The **Stable** channel gives you access to the latest **stable** release. It contains the most recent fixes, security patches, and updates while ensuring the version is thoroughly tested and stable.
- **Use Case:** Recommended for most users who need **reliable** updates and want to stay current with the latest RouterOS features.
- **Installation Action:** Clicking "Download & Install" will install the most recent stable release, suitable for general use in businesses and networks.

## 4. Testing
- **Purpose:** The **Testing** channel gives access to **beta** or **pre-release** versions of RouterOS. These versions may contain newer features but could have bugs or issues not fully addressed.
- **Use Case:** Recommended only for **advanced users** or developers who need to test new features before they are included in the stable release. Not suitable for production environments.
- **Installation Action:** Clicking "Download & Install" will install the latest **testing version**, which might be unstable.

## 5. Development
- **Purpose:** The **Development** channel includes **experimental builds** and **nightly builds** of RouterOS. These versions are usually the **earliest available** builds with the **latest features**, but they are **not stable**.
- **Use Case:** Recommended for **testing new features** or use by **developers** who want to try out the latest changes before they are incorporated into stable versions.
- **Installation Action:** Clicking "Download & Install" will install a **development build**, which might have unfinished features or experimental changes.

---

## How to Use "Download & Install":
- **Download & Install** will automatically download the chosen version from the selected channel (upgrade, long-term, stable, testing, or development) and proceed with installation. Be cautious when selecting **Testing** or **Development** as these can introduce bugs or issues in your network.

---

## In Summary:
- **Upgrade:** Latest stable version.
- **Long Term:** Long-term supported version, very stable.
- **Stable:** Regularly updated, stable versions.
- **Testing:** Beta versions for testing new features.
- **Development:** Experimental, nightly builds for advanced users or developers.
