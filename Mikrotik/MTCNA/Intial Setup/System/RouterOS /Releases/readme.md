# RouterOS Main Releases: LTS, Stable, and Testing

**RouterOS** is the operating system used by **MikroTik routers** and devices. It follows a release cycle with three primary types of versions:

- **Long-Term (LTS)**
- **Stable**
- **Testing**

## 1. Long-Term (LTS)
- **Purpose:** Provides stability and reliability for enterprise networks. The LTS version is considered "stable" for long-term use and is maintained for several years.
- **Release Frequency:** LTS versions are released approximately once every **2-3 years**.
- **Support Duration:** Each LTS version gets updates, including bug fixes, security patches, and critical improvements, for **5 years** or more.
- **Use Case:** Ideal for businesses and networks where stability and long-term support are key (e.g., data centers, large-scale enterprise environments).
- **Example:** Version **6.x** (LTS) and later versions have included critical security fixes and are ideal for long-term deployments.

## 2. Stable
- **Purpose:** Regularly updated and provides newer features, improvements, and security patches. It is the most commonly used version for most users.
- **Release Frequency:** New **Stable** releases come out roughly every **3-6 months**.
- **Support Duration:** Each release is supported for about **18 months**.
- **Use Case:** Suitable for businesses or networks that want to stay updated with newer features and enhancements without the risk of using a bleeding-edge version.
- **Example:** Version **7.x** (Stable) introduced many new features such as WireGuard VPN, improvements in routing, and enhanced security options.

## 3. Testing
- **Purpose:** The **Testing** version is essentially a "beta" release. It includes the **latest features and fixes** but may also have bugs.
- **Release Frequency:** New releases are pushed frequently, often on a **weekly basis**.
- **Support Duration:** Testing releases are **not supported long-term**. When a new stable release comes out, the testing version is often discontinued or merged into the next stable release.
- **Use Case:** Best for **developers, advanced users, or network engineers** who want to test new features, but **not for production environments**. It helps users identify bugs and report issues before they reach stable versions.
- **Example:** Testing versions in RouterOS 7.x may include experimental features for upcoming changes.

---

## How to Choose Between These Versions:
- **Long-Term (LTS):** Opt for LTS if your network must remain stable for years and you don’t need the latest features.
- **Stable:** Choose this if you want a balance between stability and having relatively up-to-date features.
- **Testing:** Only use if you're comfortable troubleshooting potential issues and want to try out the latest features before they’re available in Stable releases.
