The correct answer is **None** because here’s a summary of the **default packages** in **MikroTik RouterOS**:

1. **System**: Core functions for device configuration and management.
2. **Router**: Routing protocols (e.g., OSPF, BGP, static routing).
3. **Wireless**: Wireless interface and configuration support (802.11).
4. **Firewall**: Firewall settings, packet filtering, and NAT.
5. **DHCP**: Dynamic IP address assignment to devices.
6. **DNS**: Local DNS caching and DNS server functionality.
7. **Hotspot**: Setup and management of hotspot networks.
8. **PPP**: VPN support for PPPoE, PPTP, L2TP, etc.
9. **QoS**: Traffic management and bandwidth prioritization.
10. **VPN**: Support for VPN technologies (IPSec, OpenVPN, etc.).
11. **PPPoE**: PPPoE connections (commonly for DSL).
12. **NAT**: Network address translation for multiple devices.
13. **Routing**: Support for routing protocols like RIP, OSPF, and BGP.
14. **SNMP**: Network monitoring via Simple Network Management Protocol.

These default packages provide the basic tools for routing, network security, wireless management, and traffic control in MikroTik routers.
