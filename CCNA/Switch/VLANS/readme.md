# 🟢 VLAN Labs & Information (CCNA)

Welcome to the **VLAN folder**! This repository contains practical **labs, configurations, and reference information** for learning and practicing VLAN concepts as part of the **CCNA curriculum**.

---

## 📂 Folder Purpose

This folder is designed to help learners:

- Understand **VLAN concepts** (access vs trunk, native VLAN, VLAN types)  
- Practice **Cisco switch configurations**  
- Explore **realistic lab scenarios** for VLAN setup and troubleshooting  
- Keep all **VLAN notes, commands, and examples** in one organized place

---

## 💻 Included Content

- **Lab Exercises**  
  - Creating VLANs  
  - Assigning VLANs to access ports  
  - Configuring trunk ports  
  - Native VLAN configuration  
  - VLAN troubleshooting exercises
  - Inter Vlan Routing (Legacy - Router on a Stick - Layer 3 Switch )

- **Reference Materials**  
  - VLAN command cheat sheet  
  - Layer 2 theory and Data Link Layer concepts  
  - VLAN diagrams for better understanding  

---

## 🛠️ How to Use

1. Open the lab folder you want to practice.  
2. Follow the **instructions in each lab file**.  
3. Apply the **provided commands** on Cisco Packet Tracer, GNS3, or real switches.  
4. Use the **reference materials** to reinforce your understanding.  

---

## 📚 Recommended Tools

- **Cisco Packet Tracer** (for simulation)  
- **EVE-NG** (for advanced labs)  
- **Cisco Switches / Routers** (for real-world practice)  

---

## 📌 Notes

- Ensure you understand the **difference between access and trunk ports**.  
- Always **verify VLAN assignments** using `show vlan brief` and `show interfaces switchport`.  
- Keep practicing to **master VLAN configurations and troubleshooting**.
