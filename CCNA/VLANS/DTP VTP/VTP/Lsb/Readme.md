# VTP (VLAN Trunking Protocol) Lab 🌐

## Objective 🎯

The goal of this lab is to demonstrate the configuration and behavior of **VTP (VLAN Trunking Protocol)** in a Cisco network. VTP is used to propagate VLAN information across multiple switches in a network, allowing centralized management of VLANs.

### Topology Overview 🖼️

In this lab, we will configure the following VTP modes across multiple switches:

- **VTP Server** on `Switch8` 🖧
- **VTP Client** on `Switch9` and `Switch11` 💻
- **VTP Transparent** on `Switch10` 🔄
