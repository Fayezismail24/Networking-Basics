
# Cisco VLANs Lab

This repository contains a set of Cisco labs for configuring and managing Virtual Local Area Networks (VLANs). The labs provide hands-on experience with VLAN creation, management, and troubleshooting using Cisco devices and network simulation tools.


This repository is designed to help users learn how to configure and manage VLANs on Cisco switches and routers. It covers basic to advanced VLAN configurations, including:

- VLAN creation and assignment
- Inter-VLAN routing
- VLAN trunking
- VLAN troubleshooting
