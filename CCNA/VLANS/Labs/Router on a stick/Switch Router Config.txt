Switch Configuration 

1. Create VLANs

SW(config)#vlan 10
SW(config-vlan)#name IT
SW(config-vlan)#exit
SW(config)#vlan 20
SW(config-vlan)#name HR
SW(config-vlan)#do wr
SW(config-vlan)#exit 


2.Verify VLANs:

SW#show vlan brief // To see if the VLANS  Created Succesfully

3.Assign VLANs to Ports

SW(config)#interface fastEthernet 0/1
SW(config-if)#switchport mode access 
SW(config-if)#switchport access vlan 10
SW(config-if)#exit
SW(config)#interface fastEthernet 0/2
SW(config-if)#switchport mode access 
SW(config-if)#switchport access vlan 20
SW(config-if)#do wr
Building configuration...
[OK]
SW(config-if)#exit

6. Configure Trunk Port to Router
SW(config)#interface gigabitEthernet 0/1
SW(config-if)#switchport mode trunk 




Router Configuration : 

6.Configure Subinterfaces for VLANs:

Router>en
Router#config t
Router(config)#
Router(config)#interface gigabitEthernet 0/1
Router(config-subif)no shutdown
Router(config-subif)exit
Router(config)#interface gigabitEthernet 0/1.10
Router(config-subif)#encapsulation dot1Q 10
Router(config-subif)#ip address 192.168.1.1 255.255.255.0
Router(config-subif)#do wr
Building configuration...
[OK]
Router(config-subif)#exit
Router(config)#
Router(config)#interface gigabitEthernet 0/1.20
Router(config-subif)#encapsulation dot1Q 20
Router(config-subif)#ip address 192.168.2.1 255.255.255.0
Router(config-subif)#do wr
Building configuration...
[OK]
Router(config-subif)#exit

Router(config)#
