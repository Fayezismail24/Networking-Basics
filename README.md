🧠 Overview

This repository contains a comprehensive collection of networking labs, documentation, and practical exercises covering foundational to intermediate CCNA-level topics.
It is designed to demonstrate hands-on skills in network configuration, troubleshooting, and design, and to serve as a portfolio for potential employers.

🛠 Tools Used

🖧Cisco Packet Tracer – Lab simulations for routers, switches, and VLANs

🕵️Nmap – Network scanning, host discovery, and security assessment

📝Visual Studio Code / Markdown – Documentation and notes


🧪  Labs

📘 VLAN creation and inter-VLAN routing

🔧 SIP subnetting exercises

🌐Switch and router configuration

🛜DHCP and DNS server setup
