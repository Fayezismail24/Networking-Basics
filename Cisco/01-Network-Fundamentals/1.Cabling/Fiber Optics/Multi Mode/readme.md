

## What is Multi-Mode Fiber (MMF)?

Multi-Mode Fiber (MMF) is an optical fiber designed with a larger core that allows multiple light paths (modes) to travel through the cable simultaneously.

### Key Characteristics

* Core Diameter: 50 µm or 62.5 µm
* Cladding Diameter: 125 µm
* Light Source: LED or VCSEL
* Wavelengths: 850 nm and 1300 nm
* Short- to medium-distance transmission
* Lower cost than single-mode fiber

## Advantages

* Lower equipment cost
* Easier installation and alignment
* Commonly used in LAN environments
* Cost-effective for short distances

## Disadvantages

* Shorter transmission distances
* Higher attenuation than single-mode fiber
* Modal dispersion limits bandwidth over long distances

## Common CCNA Applications

* Enterprise LANs
* Data centers
* Campus networks
* Server-to-switch connections
* Storage Area Networks (SAN)

## Multi-Mode Fiber Types

| Fiber Type | Core Size | Typical Use                        |
| ---------- | --------- | ---------------------------------- |
| OM1        | 62.5 µm   | Legacy networks                    |
| OM2        | 50 µm     | Fast Ethernet and Gigabit Ethernet |
| OM3        | 50 µm     | 10 Gigabit Ethernet                |
| OM4        | 50 µm     | High-speed data centers            |
| OM5        | 50 µm     | Wideband multimode applications    |

## Fiber Connector Types

* LC (Lucent Connector)
* SC (Subscriber Connector)
* ST (Straight Tip)
* MPO/MTP (High-density fiber connector)

## Comparison: Multi-Mode vs Single-Mode

| Feature      | Multi-Mode      | Single-Mode |
| ------------ | --------------- | ----------- |
| Core Size    | 50/62.5 µm      | 8–10 µm     |
| Light Source | LED/VCSEL       | Laser       |
| Distance     | Short to Medium | Long        |
| Cost         | Lower           | Higher      |
| Bandwidth    | Lower           | Higher      |
