
## What is Single-Mode Fiber (SMF) ?

Single-Mode Fiber (SMF) is an optical fiber designed to carry light directly down the fiber with minimal reflections. It uses a small core diameter, allowing only one propagation mode of light.

### Key Characteristics

* Core Diameter: 8–10 µm
* Cladding Diameter: 125 µm
* Light Source: Laser
* Wavelengths: 1310 nm and 1550 nm
* Long-distance transmission
* High bandwidth capacity
* Low signal attenuation

## Advantages

* Supports distances up to tens or hundreds of kilometers
* Higher bandwidth than multimode fiber
* Less signal loss
* Better performance for backbone networks and WAN links

## Disadvantages

* Higher installation cost
* More expensive transceivers
* Requires precise fiber alignment

## Common CCNA Applications

* ISP backbone networks
* Data center interconnections
* Campus backbone links
* Metropolitan Area Networks (MAN)
* Long-distance WAN connections

## Fiber Connector Types

* LC (Lucent Connector)
* SC (Subscriber Connector)
* ST (Straight Tip)
* FC (Ferrule Connector)

## Comparison: Single-Mode vs Multi-Mode

| Feature      | Single-Mode | Multi-Mode |
| ------------ | ----------- | ---------- |
| Core Size    | 8–10 µm     | 50/62.5 µm |
| Light Source | Laser       | LED/VCSEL  |
| Distance     | Very Long   | Short      |
| Cost         | Higher      | Lower      |
| Bandwidth    | Higher      | Lower      |

## Basic Network Topology

PC → Switch → SFP Module → Single-Mode Fiber → SFP Module → Switch → Server
