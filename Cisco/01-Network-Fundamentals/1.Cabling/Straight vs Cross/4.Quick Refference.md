## Cable Type by Connection

| Connection | Same Pin Behavior? | Cable |
|------------|--------------------|-------|
| PC → Switch | ❌ Opposite | Straight-Through |
| Router → Switch | ❌ Opposite | Straight-Through |
| PC → PC | ✅ Same | Crossover |
| Router → Router | ✅ Same | Crossover |
| Switch → Switch | ✅ Same | Crossover |
| Router → PC (direct) | ✅ Same | Crossover |

---

## Device Pin Summary

| Device | TX Pins | RX Pins |
|--------|---------|---------|
| PC | 1, 2 | 3, 6 |
| Router | 1, 2 | 3, 6 |
| Switch | 3, 6 | 1, 2 |

---

## Memory Trick

```
Different devices  →  Straight-Through
Same devices       →  Crossover
```

If both ends TX on the same pins → they clash → cross them.
