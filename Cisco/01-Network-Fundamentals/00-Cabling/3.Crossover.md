# Crossover Cable

A crossover cable **crosses TX pins on one end to RX pins on the other**.  
Used when connecting **same device types** — because both devices TX on the same pins and would collide without crossing.

---

## PC ↔ PC

Both PCs transmit on pins 1,2 — straight-through causes a TX/TX collision.

```
PC #1                              PC #2
──────────                         ──────────
Pin 1 (TX+) ──────────────────▶   Pin 3 (RX+)
Pin 2 (TX-) ──────────────────▶   Pin 6 (RX-)
Pin 3 (RX+) ◀──────────────────   Pin 1 (TX+)
Pin 6 (RX-) ◀──────────────────   Pin 2 (TX-)
```

✅ PC #1 TX (1,2) → crossed → PC #2 RX (3,6)  
✅ PC #2 TX (1,2) → crossed → PC #1 RX (3,6)

---

## Switch ↔ Switch

Both switches transmit on pins 3,6 — same problem, same fix.

```
Switch #1                          Switch #2
──────────                         ──────────
Pin 3 (TX+) ──────────────────▶   Pin 1 (RX+)
Pin 6 (TX-) ──────────────────▶   Pin 2 (RX-)
Pin 1 (RX+) ◀──────────────────   Pin 3 (TX+)
Pin 2 (RX-) ◀──────────────────   Pin 6 (TX-)
```

✅ Switch #1 TX (3,6) → crossed → Switch #2 RX (1,2)  
✅ Switch #2 TX (3,6) → crossed → Switch #1 RX (1,2)

---

## Router ↔ Router

Routers behave like PCs — TX on pins 1,2 — crossover required.

```
Router #1                          Router #2
──────────                         ──────────
Pin 1 (TX+) ──────────────────▶   Pin 3 (RX+)
Pin 2 (TX-) ──────────────────▶   Pin 6 (RX-)
Pin 3 (RX+) ◀──────────────────   Pin 1 (TX+)
Pin 6 (RX-) ◀──────────────────   Pin 2 (TX-)
```

✅ Router #1 TX (1,2) → crossed → Router #2 RX (3,6)  
✅ Router #2 TX (1,2) → crossed → Router #1 RX (3,6)

---

## Router ↔ PC (Direct Connection)

Both transmit on pins 1,2 — crossover required.

```
Router                             PC
──────────                         ──────────
Pin 1 (TX+) ──────────────────▶   Pin 3 (RX+)
Pin 2 (TX-) ──────────────────▶   Pin 6 (RX-)
Pin 3 (RX+) ◀──────────────────   Pin 1 (TX+)
Pin 6 (RX-) ◀──────────────────   Pin 2 (TX-)
```

---

## Summary

| Connection | Cable |
|------------|-------|
| PC → PC | ✅ Crossover |
| Switch → Switch | ✅ Crossover |
| Router → Router | ✅ Crossover |
| Router → PC (direct) | ✅ Crossover |

> **Note:** Modern hardware with Auto-MDI/MDIX handles this automatically. The CCNA exam tests the manual logic — know it cold.
