# 01 — TX/RX Pin Overview

In **100BASE-TX Ethernet (Cat5e / Cat6)**, only 4 of the 8 pins carry data.

---

## Pin Roles by Device

| Device | Transmit (TX) | Receive (RX) |
|--------|--------------|-------------|
| PC (NIC) | **1, 2** | **3, 6** |
| Router | **1, 2** | **3, 6** |
| Switch | **3, 6** | **1, 2** |

---

## Key Insight

- PCs and Routers behave **identically** — TX on 1,2 / RX on 3,6
- Switches are the **opposite** — TX on 3,6 / RX on 1,2

This single fact explains everything:

| Connection | Pin Behavior | Result |
|------------|-------------|--------|
| PC ↔ Switch | Opposite | Pins align naturally → Straight-Through |
| Router ↔ Switch | Opposite | Pins align naturally → Straight-Through |
| PC ↔ PC | Identical | Pins clash → Crossover needed |
| Router ↔ Router | Identical | Pins clash → Crossover needed |
| Switch ↔ Switch | Identical | Pins clash → Crossover needed |

---

## RJ-45 Pin Diagram

```
Pin:  1    2    3    4    5    6    7    8
     TX+  TX-  RX+   -    -   RX-   -    -    ← PC / Router
     RX+  RX-  TX+   -    -   TX-   -    -    ← Switch
```

Pins 4, 5, 7, 8 are unused in 100BASE-TX (used in Gigabit/PoE).
