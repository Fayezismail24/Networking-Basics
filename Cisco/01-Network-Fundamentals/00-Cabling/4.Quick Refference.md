# Quick Reference

## Cable Type by Connection

| Connection | Same Pin Behavior? | Cable |
|------------|--------------------|-------|
| PC → Switch | ❌ Opposite | Straight-Through |
| Router → Switch | ❌ Opposite | Straight-Through |
| PC → PC | ✅ Same | Crossover |
| Router → Router | ✅ Same | Crossover |
| Switch → Switch | ✅ Same | Crossover |
| Router → PC (direct) | ✅ Same | Crossover |

---

## Device Pin Summary

| Device | TX Pins | RX Pins |
|--------|---------|---------|
| PC | 1, 2 | 3, 6 |
| Router | 1, 2 | 3, 6 |
| Switch | 3, 6 | 1, 2 |

---

## Memory Trick

```
Different devices  →  Straight-Through
Same devices       →  Crossover
```

If both ends TX on the same pins → they clash → cross them.

---

## CCNA Exam Note

- The exam tests this **without Auto-MDI/MDIX** — assume legacy behavior
- Routers and PCs are **treated identically** for cabling purposes
- Switch-to-switch always needs a crossover (or an uplink/trunk port that internally crosses)
- You may also see **rollover (console) cables** tested — not for data, for out-of-band CLI access (RJ-45 to DB9)
