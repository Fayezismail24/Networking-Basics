#  Straight-Through Cable

A straight-through cable connects **pin 1 → pin 1, pin 2 → pin 2**, and so on — no crossing.  
Used when connecting **different device types** because their TX/RX pins naturally complement each other.

---

## PC ↔ Switch

```
PC NIC                            Switch Port
──────────                        ──────────
Pin 1 (TX+) ──────────────────▶  Pin 1 (RX+)
Pin 2 (TX-) ──────────────────▶  Pin 2 (RX-)
Pin 3 (RX+) ◀──────────────────  Pin 3 (TX+)
Pin 6 (RX-) ◀──────────────────  Pin 6 (TX-)
```

✅ PC TX (1,2) → Switch RX (1,2)  
✅ Switch TX (3,6) → PC RX (3,6)

No crossing needed — pins align perfectly.

---

## Router ↔ Switch

```
Router                            Switch Port
──────────                        ──────────
Pin 1 (TX+) ──────────────────▶  Pin 1 (RX+)
Pin 2 (TX-) ──────────────────▶  Pin 2 (RX-)
Pin 3 (RX+) ◀──────────────────  Pin 3 (TX+)
Pin 6 (RX-) ◀──────────────────  Pin 6 (TX-)
```

✅ Router TX (1,2) → Switch RX (1,2)  
✅ Switch TX (3,6) → Router RX (3,6)

Routers and PCs have **identical pin behavior** — both use a straight-through when connecting to a switch.
