# VLAN Troubleshooting

---

## Verification Commands Cheat Sheet

### Check VLAN Database

```
show vlan brief
show vlan id <id>
show vlan name <name>
show vlan summary  ← Shows count of VLANs
show vlan internal usage  ← Shows dynamic VLAN allocation
```

### Check Port VLAN Assignment

```
show interfaces <interface> switchport
show interfaces switchport  ← All ports
show interfaces GigabitEthernet0/0/1 switchport | include VLAN
```

### Check Trunk Status

```
show interfaces trunk
show interfaces <trunk-if> trunk
show interfaces GigabitEthernet0/0/48 switchport | include Trunk
```

### Check VLAN IP Configuration (L3 Switch)

```
show ip interface brief | include Vlan
show interfaces Vlan10
show ip route  ← Verify VLAN subnets appear as connected
```

### Check Spanning Tree (affects VLAN forwarding)

```
show spanning-tree vlan 10  ← STP status for VLAN 10
show spanning-tree bridge  ← Overall STP status
```

## Troubleshooting Workflow

### Step 1: Isolate the Problem

```
Is the issue:
├─ Host cannot ping another host in same VLAN?
│  → Intra-VLAN problem (access ports, spanning-tree)
├─ Host cannot ping host in different VLAN?
│  → Inter-VLAN routing problem (SVI, routes)
├─ VLAN does not exist?
│  → Configuration error (not created)
└─ Port not forwarding traffic?
│  → Port status, STP blocking, or port security
```

### Step 2: Verify Physical Layer

```
show interfaces GigabitEthernet0/0/1
GigabitEthernet0/0/1 is up, line protocol is up

✓ Both "up" = physically connected
✗ "down, down" = cable issue, neighbor device off
```

### Step 3: Verify VLAN Membership

```
show interfaces GigabitEthernet0/0/1 switchport | include VLAN

Access Mode VLAN         : 20  ← Port assigned to VLAN 20
```

### Step 4: Check STP Status (if forwarding issues)

```
show spanning-tree vlan 20 | include GigabitEthernet0/0/1

Port     State       Role        Sts Cost      Prio.Nbr
Gi0/0/1  FWD         Desg        FWD 19       128.1

Status: FWD = forwarding ✓
Status: BLK = blocked by STP ✗
```

## Common VLAN Issues & Solutions

### Issue 1: VLAN Does Not Exist

#### Symptom
```
Switch# show vlan brief | include 15
! (No output = VLAN 15 does not exist)

Switch# configure terminal
Switch(config)# interface GigabitEthernet0/0/10
Switch(config-if)# switchport access vlan 15
% Invalid VLAN id
```

#### Root Cause
VLAN was never created.

#### Solution
```
configure terminal
vlan 15
  name NewVLAN
  exit
exit

! Now assign port
configure terminal
interface GigabitEthernet0/0/10
  switchport access vlan 15
  exit
exit
```

### Issue 2: Port Not Forwarding Traffic (Active but No Data)

#### Symptom
```
show interfaces GigabitEthernet0/0/1
GigabitEthernet0/0/1 is up, line protocol is up

show interfaces GigabitEthernet0/0/1 switchport
Access Mode VLAN         : 20  ← Correct VLAN

PC connected to Gi0/0/1 cannot ping other VLAN 20 devices
```

#### Root Cause (Check in Order)
1. **Spanning Tree blocking the port**
2. **Port security enabled** (learned max MACs)
3. **VLAN does not have any other active port** (isolated VLAN)

#### Diagnostics

**Check STP Status:**
```
show spanning-tree vlan 20

Port     State       Role
Gi0/0/1  BLK         Altn  ← BLK = Blocked (not forwarding)
```

If blocked: STP is preventing forwarding (redundancy). Check STP cost/priority.

**Check Port Security:**
```
show port-security interface GigabitEthernet0/0/1

Secure Port violation count: 3  ← Violations = port shutdown
Port Security              : Enabled
```

If violated: Port auto-shuts down. Clear with:
```
configure terminal
interface GigabitEthernet0/0/1
  shutdown
  no shutdown  ← Resets port
  exit
exit
```

**Check VLAN Status:**
```
show vlan brief | include 20
20   DataVLAN                       active    Gi0/0/1, Gi0/0/2, Gi0/0/3
```

VLAN status `active` = OK. If `suspend` = VLAN disabled (VLAN database corrupted).

### Issue 3: Native VLAN Mismatch on Trunk

#### Symptom
```
Switch A config:
interface GigabitEthernet0/0/48
  switchport mode trunk
  switchport trunk native vlan 1
  exit

Switch B config:
interface GigabitEthernet0/0/48
  switchport mode trunk
  switchport trunk native vlan 10
  exit

→ Untagged frames sent from A at native VLAN 1
→ B receives untagged, assigns to native VLAN 10
→ MISMATCH: traffic lost or misrouted
```

#### Diagnostic Commands

**Check Native VLAN:**
```
show interfaces trunk

Port        Mode    Native VLAN
Gi0/0/48    on      1  ← Switch A

Port        Mode    Native VLAN
Gi0/0/48    on      10  ← Switch B
→ MISMATCH DETECTED
```

**Or per interface:**
```
show interfaces GigabitEthernet0/0/48 switchport | include Native

Trunking Vlans Native    : 1  ← Or 10 on the other switch
```

#### Solution

Make both sides match:

**Switch A & B (both):**
```
configure terminal
interface GigabitEthernet0/0/48
  switchport trunk native vlan 999  ← Unused VLAN
  exit
exit
```

Verify:
```
show interfaces trunk | include Native
Native VLAN = 999 (both switches now)
```

### Issue 4: VLAN Not Allowed on Trunk

#### Symptom
```
Switch A trunk config:
switchport trunk allowed vlan 1,10,20

Switch B wants to send VLAN 30 traffic → Trunk does not allow it
→ VLAN 30 frames discarded
```

#### Diagnostic

**Check allowed VLANs:**
```
show interfaces trunk

Port        Vlans allowed on trunk
Gi0/0/48    1,10,20  ← VLAN 30 is NOT listed
```

#### Solution

Add VLAN to allowed list:

```
configure terminal
interface GigabitEthernet0/0/48
  switchport trunk allowed vlan add 30
  exit
exit
```

Verify:
```
show interfaces trunk

Port        Vlans allowed on trunk
Gi0/0/48    1,10,20,30  ← VLAN 30 added
```

### Issue 5: Inter-VLAN Communication Fails (L3 Switch)

#### Symptom
```
VLAN 10 host: 192.168.10.100
VLAN 20 host: 192.168.20.100
Default gateway (both): 192.168.10.1 / 192.168.20.1 (SVIs)

VLAN 10 host> ping 192.168.20.100
→ Request times out (no response)
```

#### Root Cause (Check in Order)

1. **IP routing not enabled**
2. **SVI interface down**
3. **SVI IP not configured**
4. **ACL blocking traffic**

#### Diagnostics

**Check routing enabled:**
```
show ip route

! If output shows routes (C = connected)
! routing is enabled ✓

! If output is empty or "Codes:" only
! routing is NOT enabled ✗
```

**Check SVI status:**
```
show interfaces Vlan10 | include up

Vlan10 is up, line protocol is up  ✓

OR

Vlan10 is down, line protocol is down  ✗
```

**Check SVI IP:**
```
show interfaces Vlan10 | include Internet

Internet address is 192.168.10.1/24  ✓
```

**Check routing table:**
```
show ip route

C       192.168.10.0/24 is directly connected, Vlan10
C       192.168.20.0/24 is directly connected, Vlan20
```

Both VLANs should appear.

#### Solution

If routing not enabled:
```
configure terminal
ip routing
exit
```

If SVI down:
```
configure terminal
interface Vlan10
  no shutdown
  exit
exit
```

If SVI missing IP:
```
configure terminal
interface Vlan20
  ip address 192.168.20.1 255.255.255.0
  no shutdown
  exit
exit
```

### Issue 6: DTP Causing Unexpected Trunking

#### Symptom
```
Access port accidentally becomes trunk
PC on Gi0/0/10 can now see all VLAN traffic (VLAN hopping)
```

#### Diagnostic

**Check port mode:**
```
show interfaces GigabitEthernet0/0/10 switchport

Administrative Mode      : dynamic desirable  ← DTP enabled!
Operational Mode         : trunk  ← Should be access!
```

#### Solution

**Disable DTP on all ports:**
```
configure terminal
interface GigabitEthernet0/0/10
  switchport mode access  ← Explicit mode
  switchport nonegotiate  ← Disable DTP
  exit
exit
```

**Verify:**
```
show interfaces GigabitEthernet0/0/10 switchport

Administrative Mode      : static access
Operational Mode         : access
Administrative Trunking  : disabled  ← DTP off
```

## Comprehensive Troubleshooting Checklist

### Intra-VLAN Connectivity (Same VLAN)

- [ ] Both hosts in same VLAN? (`show vlan brief`)
- [ ] Both ports up? (`show interfaces <if> | include up`)
- [ ] Correct VLAN assigned? (`show interfaces <if> switchport`)
- [ ] STP forwarding (not blocked)? (`show spanning-tree vlan <id>`)
- [ ] Port security not violated? (`show port-security`)
- [ ] VLAN status active? (`show vlan brief | include VLAN#`)

### Inter-VLAN Connectivity (Different VLANs)

- [ ] IP routing enabled? (`show ip routing`)
- [ ] All VLANs created? (`show vlan brief`)
- [ ] SVIs configured with IPs? (`show interfaces Vlan<id>`)
- [ ] SVIs up? (`show interfaces Vlan<id> | include up`)
- [ ] Routing table shows VLANs? (`show ip route`)
- [ ] Hosts have correct default gateway? (Host config check)
- [ ] ACLs not blocking traffic? (`show access-lists`)

### Trunk Connectivity

- [ ] Trunk configured? (`show interfaces trunk`)
- [ ] Native VLAN matches on both sides? (`show interfaces trunk | include Native`)
- [ ] Required VLANs allowed? (`show interfaces trunk | include allowed`)
- [ ] Physical link up? (`show interfaces <trunk-if> | include up`)
