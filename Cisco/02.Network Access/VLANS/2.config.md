# VLAN Configuration

---

## Creating VLANs

### Step 1: Enter Global Config Mode
```
Device# configure terminal
Device(config)#
```

### Step 2: Create VLAN and Assign Name
```
Device(config)# vlan 10
Device(config-vlan)# name Management
Device(config-vlan)# exit
```

### Step 3: Repeat for Additional VLANs
```
Device(config)# vlan 20
Device(config-vlan)# name Data
Device(config-vlan)# exit

Device(config)# vlan 30
Device(config-vlan)# name Voice
Device(config-vlan)# exit
```

### Verify VLANs Created
```
Device# show vlan brief
VLAN Name                             Status    Ports
---- -------------------------------- --------- -------
1    default                          active    Gi0/0/1, Gi0/0/2...
10   Management                       active    
20   Data                             active    
30   Voice                            active
```

## Configuring Access Ports

An **access port** belongs to one VLAN and sends/receives untagged frames.

### Single Access Port

```
Device(config)# interface GigabitEthernet0/0/1
Device(config-if)# switchport mode access
Device(config-if)# switchport access vlan 10
Device(config-if)# description PC-Management
Device(config-if)# exit
```

### Multiple Access Ports (Range)

```
Device(config)# interface range GigabitEthernet0/0/1-10
Device(config-if-range)# switchport mode access
Device(config-if-range)# switchport access vlan 10
Device(config-if-range)# description Management-PCs
Device(config-if-range)# exit
```

### Verify Access Port Configuration

```
Device# show interfaces GigabitEthernet0/0/1 switchport
Name                      : Gi0/0/1
Switchport               : Enabled
Administrative Mode      : static access
Operational Mode         : static access
Administrative Trunking  : disabled
Operational Trunking     : off
Access Mode VLAN         : 10
Trunking VLANs Enabled   : ALL
Trunking Vlans Native    : 1
```

## Configuration Lab: 3-VLAN Setup

### Network Design
```
┌───────────────────────────────────────┐
│  Cisco Catalyst 3560-48               │
├───────────────────────────────────────┤
│ VLAN 10 (Mgmt)  : Gi0/0/1-4           │
│ VLAN 20 (Data)  : Gi0/0/11-20         │
│ VLAN 30 (Voice) : Gi0/0/21-30         │
│ Trunk           : Gi0/0/48 (to router)│
└───────────────────────────────────────┘
```

### Full Configuration

#### Step 1: Create VLANs
```
configure terminal

vlan 10
  name Management
  exit

vlan 20
  name Data
  exit

vlan 30
  name Voice
  exit

exit
```

#### Step 2: Configure Management Ports (VLAN 10)
```
configure terminal

interface range GigabitEthernet0/0/1-4
  switchport mode access
  switchport access vlan 10
  description Management-Workstations
  exit

exit
```

#### Step 3: Configure Data Ports (VLAN 20)
```
configure terminal

interface range GigabitEthernet0/0/11-20
  switchport mode access
  switchport access vlan 20
  description Data-Workstations
  exit

exit
```

#### Step 4: Configure Voice Ports (VLAN 30)
```
configure terminal

interface range GigabitEthernet0/0/21-30
  switchport mode access
  switchport access vlan 30
  description IP-Phones
  exit

exit
```

#### Step 5: Configure Trunk to Router
```
configure terminal

interface GigabitEthernet0/0/48
  switchport mode trunk
  switchport trunk native vlan 1
  switchport trunk allowed vlan 1,10,20,30
  description Trunk-to-Router
  exit

exit
```

### Verification

```
show vlan brief
show interfaces trunk
show interfaces GigabitEthernet0/0/48 switchport
show interfaces GigabitEthernet0/0/1 switchport
```

## Configuring Trunk Ports

A **trunk port** carries multiple VLANs using 802.1Q tags.

### Basic Trunk Configuration

```
Device(config)# interface GigabitEthernet0/0/48
Device(config-if)# switchport mode trunk
Device(config-if)# switchport trunk native vlan 1
Device(config-if)# exit
```

### Trunk with Allowed VLANs (Filtered)

```
Device(config)# interface GigabitEthernet0/0/48
Device(config-if)# switchport mode trunk
Device(config-if)# switchport trunk native vlan 1
Device(config-if)# switchport trunk allowed vlan 1,10,20,30
Device(config-if)# exit
```

### Allow All VLANs (Default)

```
Device(config)# interface GigabitEthernet0/0/48
Device(config-if)# switchport mode trunk
Device(config-if)# switchport trunk allowed vlan all
Device(config-if)# exit
```

### Remove VLANs from Trunk

```
Device(config)# interface GigabitEthernet0/0/48
Device(config-if)# switchport trunk allowed vlan remove 40,50
Device(config-if)# exit
```

### Add VLANs to Trunk

```
Device(config)# interface GigabitEthernet0/0/48
Device(config-if)# switchport trunk allowed vlan add 40,50
Device(config-if)# exit
```

## Native VLAN Configuration

The **native VLAN** is the untagged VLAN on a trunk. Default is VLAN 1 (NOT RECOMMENDED for security).

### Change Native VLAN to VLAN 10

```
Device(config)# interface GigabitEthernet0/0/48
Device(config-if)# switchport trunk native vlan 10
Device(config-if)# exit
```

### Verify Native VLAN

```
Device# show interfaces trunk | include native
Trunking Vlans Native    : 10
```

⚠️ **Native VLAN Mismatch Risk**:
- If one side of trunk is native VLAN 1, other is native VLAN 10
- Untagged frames on VLAN 10 arrive untagged, assigned to VLAN 1
- **Result**: Data loss or unexpected VLAN assignment

## Deleting VLANs

### Delete Single VLAN

```
Device# configure terminal
Device(config)# no vlan 20
Device(config)# exit
```

### Verify Deletion

```
Device# show vlan brief | include 20
! (Output shows VLAN 20 no longer listed)
```

⚠️ **Before Deleting**: Ensure no access ports are assigned to that VLAN. Ports will become inactive if their assigned VLAN is deleted.

### Reset All VLANs to Default

```
Device# delete flash:vlan.dat
Device# reload
```

## VLAN Database Summary

| Command | Purpose |
|---------|---------|
| `vlan <id>` | Create or enter VLAN config mode |
| `name <name>` | Assign VLAN name |
| `no vlan <id>` | Delete VLAN |
| `show vlan brief` | List all VLANs |
| `show vlan id <id>` | Show specific VLAN details |
| `show vlan name <name>` | Show VLAN by name |

## Practical Configuration Checklist

- [ ] Plan VLAN design (IDs, names, purpose)
- [ ] Create all VLANs with descriptive names
- [ ] Configure access ports for each VLAN (use ranges)
- [ ] Configure trunk to router or other switch
- [ ] Set native VLAN on trunk (avoid VLAN 1)
- [ ] Filter allowed VLANs on trunk (if needed)
- [ ] Test connectivity:
  - Within VLAN: `ping` between hosts
  - Across VLAN: Requires Layer 3 routing
- [ ] Document port assignments in running-config backup
- [ ] Copy running-config to startup-config: `copy running-config startup-config`

## Common Configuration Mistakes

| Mistake | Symptom | Fix |
|---------|---------|-----|
| Access port not assigned | Interface inactive for traffic | `switchport access vlan <id>` |
| Trunk not created | VLANs cannot span switches | `switchport mode trunk` |
| Native VLAN mismatch | Untagged traffic lost/misrouted | Match native VLAN on both sides |
| Allowed VLANs filtered | VLAN access denied | Add VLAN to `allowed vlan` list |
| DTP enabled (insecure) | Unexpected trunking | Disable DTP: `switchport mode on` |
